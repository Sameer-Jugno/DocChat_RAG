================================================================================
HOW TO RUN DocChat RAG IN VS CODE
================================================================================

WHICH FOLDER TO OPEN?
---------------------
Use:  DocChat_RAG

  Path (this machine):
    /home/dev/Desktop/3Hr_project/DocChat_RAG

  Why:
    - This is the GitHub repo: https://github.com/Sameer-Jugno/DocChat_RAG
    - This is the folder you should develop, commit, and push from.

Do NOT use pdf-chat for GitHub work.
  - pdf-chat was the original local build folder.
  - DocChat_RAG is the cleaned copy linked to GitHub.
  - Prefer DocChat_RAG only to avoid editing two copies.


--------------------------------------------------------------------------------
ONE-TIME SETUP
--------------------------------------------------------------------------------

1) Open VS Code
   File → Open Folder → select DocChat_RAG

2) Open Terminal in VS Code
   Terminal → New Terminal
   (cwd should be DocChat_RAG)

3) Create / activate virtualenv
   python3 -m venv .venv
   source .venv/bin/activate

4) Install dependencies
   pip install -r requirements.txt

5) Create .env (required for chat)
   cp .env.example .env
   # Edit .env and set:
   GROQ_API_KEY=your_key_here

6) Select Python interpreter in VS Code
   Ctrl+Shift+P → "Python: Select Interpreter"
   → choose ./.venv/bin/python

7) Start Qdrant (vector DB)
   docker compose up -d
   # check: curl http://localhost:6333/readyz


--------------------------------------------------------------------------------
RUN THE APP (EVERY TIME)
--------------------------------------------------------------------------------

In VS Code terminal (inside DocChat_RAG, venv active):

  source .venv/bin/activate
  docker compose up -d
  PYTHONPATH=. chainlit run app_ui.py --host 0.0.0.0 --port 8000

Then open in browser:
  http://localhost:8000

Upload a file from data/samples/ and chat.


--------------------------------------------------------------------------------
STOP / TROUBLESHOOT
--------------------------------------------------------------------------------

Stop the app:
  Ctrl+C in the terminal

If "port 8000 already in use":
  fuser -k 8000/tcp
  # then run chainlit again

If upload/index fails:
  - Confirm docker Qdrant is up
  - Confirm GROQ_API_KEY is set in .env
  - Hard-refresh the browser (Ctrl+Shift+R)

Optional API only (not required for UI):
  PYTHONPATH=. uvicorn app.api:app --host 0.0.0.0 --port 8001
